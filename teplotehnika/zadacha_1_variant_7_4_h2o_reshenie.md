# Задача 1. Политропное сжатие H2O

Новый вариант:

```text
Таблица 1 - вариант 7
Таблица 2 - вариант 4
Таблица 3 - газ H2O
```

Готовые графики:

```text
teplotehnika/zadacha_1_variant_7_4_h2o_pv.svg
teplotehnika/zadacha_1_variant_7_4_h2o_ts.svg
```

## 1. Исходные данные

Из таблицы 1, вариант 7:

```text
P1 = 22 бар
N = P2 / P1 = 12
m = 3 кг
n = 1,31
```

Из таблицы 2, вариант 4:

```text
t1 = 550 °C
```

Для газа H2O принимаем:

```text
R = 0,4615 кДж/(кг*K)
cv = 1,38 кДж/(кг*K)
cp = 1,8415 кДж/(кг*K)
```

Переводим температуру:

```text
T1 = t1 + 273
T1 = 550 + 273 = 823 K
```

Переводим давление:

```text
P1 = 22 бар = 2200 кПа
```

## 2. Конечное давление

```text
P2 = N * P1
P2 = 12 * 22
P2 = 264 бар
```

В кПа:

```text
P2 = 264 бар = 26400 кПа
```

## 3. Конечная температура

Для политропного процесса:

```text
T2 / T1 = (P2 / P1)^((n - 1) / n)
```

Так как `P2 / P1 = N`:

```text
T2 = T1 * N^((n - 1) / n)
```

Подставляем:

```text
T2 = 823 * 12^((1,31 - 1) / 1,31)
T2 = 823 * 12^(0,31 / 1,31)
T2 = 823 * 12^0,2366
T2 = 823 * 1,800
T2 = 1482 K
```

В градусах Цельсия:

```text
t2 = T2 - 273
t2 = 1482 - 273 = 1209 °C
```

## 4. Удельные объемы

Используем уравнение состояния идеального газа:

```text
P * v = R * T
```

Отсюда:

```text
v = R * T / P
```

Начальный удельный объем:

```text
v1 = R * T1 / P1
v1 = 0,4615 * 823 / 2200
v1 = 0,1726 м3/кг
```

Конечный удельный объем:

```text
v2 = R * T2 / P2
v2 = 0,4615 * 1482 / 26400
v2 = 0,0259 м3/кг
```

## 5. Изменение внутренней энергии

```text
Delta U = m * cv * (T2 - T1)
```

Разность температур:

```text
T2 - T1 = 1482 - 823 = 659 K
```

Подставляем:

```text
Delta U = 3 * 1,38 * 659
Delta U = 2727 кДж
```

Ответ:

```text
Delta U = +2727 кДж
```

Знак плюс означает, что внутренняя энергия увеличилась.

## 6. Работа сжатия

Работа газа в политропном процессе:

```text
Lгаз = m * R * (T2 - T1) / (1 - n)
```

Подставляем:

```text
Lгаз = 3 * 0,4615 * 659 / (1 - 1,31)
Lгаз = 912 / (-0,31)
Lгаз = -2942 кДж
```

Работа сжатия по модулю:

```text
Lсж = 2942 кДж
```

## 7. Количество отведенного тепла

Первый закон термодинамики:

```text
Q = Delta U + Lгаз
```

Подставляем:

```text
Q = 2727 + (-2942)
Q = -215 кДж
```

Знак минус означает, что тепло отводится от газа.

```text
Qотв = 215 кДж
```

## 8. Итоговые ответы

```text
P2 = 264 бар
T2 = 1482 K
t2 = 1209 °C
v1 = 0,1726 м3/кг
v2 = 0,0259 м3/кг
Delta U = +2727 кДж
Lгаз = -2942 кДж
Lсж = 2942 кДж
Q = -215 кДж
Qотв = 215 кДж
```


## 10. Точки для графика T-s

Для построения принимаем:

```text
s1 = 0
```

Изменение энтропии:

```text
Delta s = cp * ln(T / T1) - R * ln(P / P1)
```

Для конечной точки:

```text
Delta s2 = 1,8415 * ln(1482 / 823) - 0,4615 * ln(264 / 22)
Delta s2 = -0,064 кДж/(кг*K)
```
