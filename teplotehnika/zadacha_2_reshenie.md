# Задача 2. Сравнение двух циклов Ренкина

Нужно сравнить применение пара с разными начальными параметрами и разным конечным давлением.
Расчет выполняется по `i-S` диаграмме водяного пара.

## 1. Исходные данные

Для первого цикла берем таблицу 1, вариант 0:

```text
P1 = 14 бар
t1 = 250 °C
P2 = 0,1 бар
```

Для второго цикла берем таблицу 2, вариант 4:

```text
P1 = 120 бар
t1 = 400 °C
P2 = 0,03 бар
```

Обозначения:

```text
i - энтальпия, кДж/кг
S - энтропия, кДж/(кг*K)
x - степень сухости пара
H0 - располагаемый теплоперепад, кДж/кг
d0 - удельный расход пара, кг/(кВт*ч)
eta_t - термический КПД цикла
```

В учебном расчете насосной работой пренебрегаем, потому что она мала по сравнению с работой турбины.

Готовая диаграмма:

```text

```

## 2. Формулы для записи

Расширение пара в идеальной турбине принимаем изоэнтропным:

```text
S2 = S1
```

Если конечная точка попадает в область влажного пара, степень сухости:

```text
x2 = (S2 - S') / (S'' - S')
```

Здесь:

```text
S'  - энтропия насыщенной воды при давлении P2
S'' - энтропия сухого насыщенного пара при давлении P2
```

Энтальпия в конце расширения:

```text
i2 = i' + x2 * (i'' - i')
```

Располагаемый теплоперепад:

```text
H0 = i1 - i2
```

Количество теплоты, подведенное в котле:

```text
q1 = i1 - i3
```

Здесь `i3 = i'` - энтальпия насыщенной воды при конечном давлении `P2`.

Термический КПД:

```text
eta_t = H0 / q1
```

Удельный расход пара:

```text
d0 = 3600 / H0
```

Число `3600` берется потому, что:

```text
1 кВт*ч = 3600 кДж
```

## 3. Первый цикл

Дано:

```text
P1 = 14 бар
t1 = 250 °C
P2 = 0,1 бар
```

По `i-S` диаграмме для начальной точки:

```text
i1 = 2928 кДж/кг
S1 = 6,749 кДж/(кг*K)
```

Так как расширение изоэнтропное:

```text
S2 = S1 = 6,749 кДж/(кг*K)
```

При `P2 = 0,1 бар` по таблицам насыщения:

```text
i' = 192 кДж/кг
S' = 0,649 кДж/(кг*K)
i'' = 2584 кДж/кг
S'' = 8,149 кДж/(кг*K)
```

Степень сухости:

```text
x2 = (S2 - S') / (S'' - S')
x2 = (6,749 - 0,649) / (8,149 - 0,649)
x2 = 6,100 / 7,500
x2 = 0,813
```

Энтальпия в конце расширения:

```text
i2 = i' + x2 * (i'' - i')
i2 = 192 + 0,813 * (2584 - 192)
i2 = 2137 кДж/кг
```

Располагаемый теплоперепад:

```text
H0 = i1 - i2
H0 = 2928 - 2137
H0 = 791 кДж/кг
```

Подведенная теплота:

```text
q1 = i1 - i3
q1 = 2928 - 192
q1 = 2736 кДж/кг
```

Термический КПД:

```text
eta_t = H0 / q1
eta_t = 791 / 2736
eta_t = 0,289 = 28,9 %
```

Удельный расход пара:

```text
d0 = 3600 / H0
d0 = 3600 / 791
d0 = 4,55 кг/(кВт*ч)
```

## 4. Второй цикл

Дано:

```text
P1 = 120 бар
t1 = 400 °C
P2 = 0,03 бар
```

По `i-S` диаграмме для начальной точки:

```text
i1 = 3052 кДж/кг
S1 = 6,076 кДж/(кг*K)
```

Так как расширение изоэнтропное:

```text
S2 = S1 = 6,076 кДж/(кг*K)
```

При `P2 = 0,03 бар` по таблицам насыщения:

```text
i' = 101 кДж/кг
S' = 0,354 кДж/(кг*K)
i'' = 2545 кДж/кг
S'' = 8,577 кДж/(кг*K)
```

Степень сухости:

```text
x2 = (S2 - S') / (S'' - S')
x2 = (6,076 - 0,354) / (8,577 - 0,354)
x2 = 5,722 / 8,223
x2 = 0,696
```

Энтальпия в конце расширения:

```text
i2 = i' + x2 * (i'' - i')
i2 = 101 + 0,696 * (2545 - 101)
i2 = 1802 кДж/кг
```

Располагаемый теплоперепад:

```text
H0 = i1 - i2
H0 = 3052 - 1802
H0 = 1250 кДж/кг
```

Подведенная теплота:

```text
q1 = i1 - i3
q1 = 3052 - 101
q1 = 2951 кДж/кг
```

Термический КПД:

```text
eta_t = H0 / q1
eta_t = 1250 / 2951
eta_t = 0,424 = 42,4 %
```

Удельный расход пара:

```text
d0 = 3600 / H0
d0 = 3600 / 1250
d0 = 2,88 кг/(кВт*ч)
```

## 5. Сводная таблица

| `t1`, °C | 250 | 400 |

| `i1`, кДж/кг | 2928 | 3052 |
| `S1`, кДж/(кг*K) | 6,749 | 6,076 |
| `i2`, кДж/кг | 2137 | 1802 |

| `eta_t`, % | 28,9 | 42,4 |
| `d0`, кг/(кВт*ч) | 4,55 | 2,88 |

## 6. Вывод

При повышении начального давления и снижении конечного давления:

```text
располагаемый теплоперепад увеличивается:
791 -> 1250 кДж/кг

термический КПД увеличивается:
28,9 % -> 42,4 %

удельный расход пара уменьшается:
4,55 -> 2,88 кг/(кВт*ч)
```

То есть второй цикл энергетически выгоднее.

Но степень сухости в конце расширения уменьшается:

```text
x2 = 0,813 -> 0,696
```

Это означает, что во втором цикле влажность пара в конце турбины больше. Слишком влажный пар вреден для лопаток турбины, поэтому на практике применяют перегрев, промежуточный перегрев или другие способы уменьшения влажности.

## 7. Как вручную нарисовать i-S диаграмму

1. По горизонтали отложить `S`, кДж/(кг*K).
2. По вертикали отложить `i`, кДж/кг.
3. Нарисовать купол насыщения.
4. Для первого цикла отметить:

```text
точка I1: S = 6,749; i = 2928
точка I2: S = 6,749; i = 2137
точка I3: S = 0,649; i = 192
```

5. Для второго цикла отметить:

```text
точка II1: S = 6,076; i = 3052
точка II2: S = 6,076; i = 1802
точка II3: S = 0,354; i = 101
```

6. Линия `1-2` для каждого цикла вертикальная вниз, потому что:

```text
S2 = S1
```
