# Задача 3. Теплопередача через плоскую стальную стенку

Новый вариант:

```text
Таблица 1 - вариант 7
Таблица 2 - вариант 4
delta_н = 0,15 мм
delta_c = 10 * delta_н
```

Готовая эпюра:

```text
teplotehnika/zadacha_3_variant_7_4_temperature_profile.svg
```

## 1. Исходные данные

Из таблицы 1, вариант 7:

```text
t2 = 20 °C
alpha2 = 125 Вт/(м2*K)
```

Из таблицы 2, вариант 4:

```text
t1 = 450 °C
alpha1 = 5400 Вт/(м2*K)
```

По условию:

```text
lambda_c = 58 Вт/(м*K)
lambda_н = 3 Вт/(м*K)
delta_н = 0,15 мм
delta_c = 10 * delta_н
```

Переводим толщины в метры:

```text
delta_н = 0,15 мм = 0,00015 м
delta_c = 10 * 0,15 = 1,5 мм = 0,0015 м
```

Разность температур:

```text
t1 - t2 = 450 - 20 = 430 °C
```

## 2. Расчет без накипи

Общее термическое сопротивление:

```text
R = 1/alpha1 + delta_c/lambda_c + 1/alpha2
```

Подставляем:

```text
R = 1/5400 + 0,0015/58 + 1/125
R = 0,000185 + 0,0000259 + 0,008000
R = 0,008211 м2*K/Вт
```

Коэффициент теплопередачи:

```text
k = 1/R
k = 1/0,008211
k = 121,8 Вт/(м2*K)
```

Удельный тепловой поток:

```text
q = k * (t1 - t2)
q = 121,8 * 430
q = 52368 Вт/м2
```

Или:

```text
q = 52,4 кВт/м2
```

### Температуры поверхностей стенки

Температура поверхности стали со стороны газов:

```text
tст1 = t1 - q/alpha1
tст1 = 450 - 52368/5400
tст1 = 450 - 9,70
tст1 = 440,3 °C
```

Температура поверхности стали со стороны воды:

```text
tст2 = tст1 - q * delta_c/lambda_c
tст2 = 440,3 - 52368 * 0,0015/58
tст2 = 440,3 - 1,35
tст2 = 438,9 °C
```

Проверка:

```text
tст2 = t2 + q/alpha2
tст2 = 20 + 52368/125
tст2 = 438,9 °C
```

## 3. Расчет с накипью

Добавляем сопротивление слоя накипи:

```text
delta_н/lambda_н
```

Общее термическое сопротивление:

```text
R = 1/alpha1 + delta_н/lambda_н + delta_c/lambda_c + 1/alpha2
```

Подставляем:

```text
R = 1/5400 + 0,00015/3 + 0,0015/58 + 1/125
R = 0,000185 + 0,000050 + 0,0000259 + 0,008000
R = 0,008261 м2*K/Вт
```

Коэффициент теплопередачи:

```text
k = 1/R
k = 1/0,008261
k = 121,1 Вт/(м2*K)
```

Удельный тепловой поток:

```text
q = k * (t1 - t2)
q = 121,1 * 430
q = 52052 Вт/м2
```

Или:

```text
q = 52,1 кВт/м2
```

### Температуры поверхностей

Температура наружной поверхности накипи со стороны газов:

```text
tн1 = t1 - q/alpha1
tн1 = 450 - 52052/5400
tн1 = 440,4 °C
```

Температура поверхности стали под накипью:

```text
tст1 = tн1 - q * delta_н/lambda_н
tст1 = 440,4 - 52052 * 0,00015/3
tст1 = 440,4 - 2,60
tст1 = 437,8 °C
```

Температура поверхности стали со стороны воды:

```text
tст2 = tст1 - q * delta_c/lambda_c
tст2 = 437,8 - 52052 * 0,0015/58
tст2 = 436,4 °C
```

Проверка:

```text
tст2 = t2 + q/alpha2
tст2 = 20 + 52052/125
tст2 = 436,4 °C
```

## 6. Короткий вариант для переписывания

```text
Дано:
t1 = 450 °C; t2 = 20 °C;
alpha1 = 5400 Вт/(м2*K); alpha2 = 125 Вт/(м2*K);
lambda_c = 58 Вт/(м*K); lambda_н = 3 Вт/(м*K);
delta_н = 0,15 мм = 0,00015 м;
delta_c = 10*delta_н = 1,5 мм = 0,0015 м.

Без накипи:
R = 1/alpha1 + delta_c/lambda_c + 1/alpha2
R = 1/5400 + 0,0015/58 + 1/125 = 0,008211 м2*K/Вт.
k = 1/R = 121,8 Вт/(м2*K).
q = k*(t1-t2) = 121,8*(450-20) = 52368 Вт/м2 = 52,4 кВт/м2.
tст1 = t1 - q/alpha1 = 440,3 °C.
tст2 = t2 + q/alpha2 = 438,9 °C.

С накипью:
R = 1/alpha1 + delta_н/lambda_н + delta_c/lambda_c + 1/alpha2
R = 1/5400 + 0,00015/3 + 0,0015/58 + 1/125 = 0,008261 м2*K/Вт.
k = 1/R = 121,1 Вт/(м2*K).
q = k*(t1-t2) = 121,1*(450-20) = 52052 Вт/м2 = 52,1 кВт/м2.
tн1 = t1 - q/alpha1 = 440,4 °C.
tст1 = tн1 - q*delta_н/lambda_н = 437,8 °C.
tст2 = t2 + q/alpha2 = 436,4 °C.
```
