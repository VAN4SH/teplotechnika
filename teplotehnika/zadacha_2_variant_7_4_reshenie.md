# Задача 2. Сравнение двух циклов Ренкина

Новый вариант:

```text
Таблица 1 - вариант 7
Таблица 2 - вариант 4
```

Готовая i-S диаграмма:

```text
teplotehnika/zadacha_2_variant_7_4_is.svg
```

## 1. Исходные данные

Первый цикл, таблица 1 вариант 7:

```text
P1 = 50 бар
t1 = 340 °C
P2 = 0,24 бар
```

Второй цикл, таблица 2 вариант 4:

```text
P1 = 120 бар
t1 = 400 °C
P2 = 0,03 бар
```

## 2. Формулы для записи

Расширение в идеальной турбине считаем изоэнтропным:

```text
S2 = S1
```

Степень сухости в конце расширения:

```text
x2 = (S2 - S') / (S'' - S')
```

Энтальпия влажного пара:

```text
i2 = i' + x2 * (i'' - i')
```

Располагаемый теплоперепад:

```text
H0 = i1 - i2
```

Подведенная теплота:

```text
q1 = i1 - i3
```

Термический КПД:

```text
eta_t = H0 / q1
```

Удельный расход пара:

```text
d0 = 3600 / H0
```

## 3. Первый цикл

Дано:

```text
P1 = 50 бар
t1 = 340 °C
P2 = 0,24 бар
```

По i-S диаграмме для начальной точки:

```text
i1 = 3042 кДж/кг
S1 = 6,408 кДж/(кг*K)
```

Так как расширение изоэнтропное:

```text
S2 = S1 = 6,408 кДж/(кг*K)
```

При `P2 = 0,24 бар`:

```text
i' = 268 кДж/кг
S' = 0,882 кДж/(кг*K)
i'' = 2616 кДж/кг
S'' = 7,844 кДж/(кг*K)
```

Степень сухости:

```text
x2 = (S2 - S') / (S'' - S')
x2 = (6,408 - 0,882) / (7,844 - 0,882)
x2 = 5,526 / 6,962
x2 = 0,794
```

Энтальпия в конце расширения:

```text
i2 = i' + x2 * (i'' - i')
i2 = 268 + 0,794 * (2616 - 268)
i2 = 2132 кДж/кг
```

Располагаемый теплоперепад:

```text
H0 = i1 - i2
H0 = 3042 - 2132
H0 = 911 кДж/кг
```

Подведенная теплота:

```text
q1 = i1 - i3
q1 = 3042 - 268
q1 = 2774 кДж/кг
```

Термический КПД:

```text
eta_t = H0 / q1
eta_t = 911 / 2774
eta_t = 0,328 = 32,8 %
```

Удельный расход пара:

```text
d0 = 3600 / H0
d0 = 3600 / 911
d0 = 3,95 кг/(кВт*ч)
```

## 4. Второй цикл

Дано:

```text
P1 = 120 бар
t1 = 400 °C
P2 = 0,03 бар
```

По i-S диаграмме для начальной точки:

```text
i1 = 3052 кДж/кг
S1 = 6,076 кДж/(кг*K)
```

Так как расширение изоэнтропное:

```text
S2 = S1 = 6,076 кДж/(кг*K)
```

При `P2 = 0,03 бар`:

```text
i' = 101 кДж/кг
S' = 0,354 кДж/(кг*K)
i'' = 2545 кДж/кг
S'' = 8,577 кДж/(кг*K)
```

Степень сухости:

```text
x2 = (S2 - S') / (S'' - S')
x2 = (6,076 - 0,354) / (8,577 - 0,354)
x2 = 5,722 / 8,223
x2 = 0,696
```

Энтальпия в конце расширения:

```text
i2 = i' + x2 * (i'' - i')
i2 = 101 + 0,696 * (2545 - 101)
i2 = 1802 кДж/кг
```

Располагаемый теплоперепад:

```text
H0 = i1 - i2
H0 = 3052 - 1802
H0 = 1250 кДж/кг
```

Подведенная теплота:

```text
q1 = i1 - i3
q1 = 3052 - 101
q1 = 2951 кДж/кг
```

Термический КПД:

```text
eta_t = H0 / q1
eta_t = 1250 / 2951
eta_t = 0,424 = 42,4 %
```

Удельный расход пара:

```text
d0 = 3600 / H0
d0 = 3600 / 1250
d0 = 2,88 кг/(кВт*ч)
```

## 5. Сводная таблица

| Показатель | Цикл 1 | Цикл 2 |
|---|---:|---:|
| `P1`, бар | 50 | 120 |
| `t1`, °C | 340 | 400 |
| `P2`, бар | 0,24 | 0,03 |
| `i1`, кДж/кг | 3042 | 3052 |
| `S1`, кДж/(кг*K) | 6,408 | 6,076 |
| `i2`, кДж/кг | 2132 | 1802 |
| `x2` | 0,794 | 0,696 |
| `H0`, кДж/кг | 911 | 1250 |
| `q1`, кДж/кг | 2774 | 2951 |
| `eta_t`, % | 32,8 | 42,4 |
| `d0`, кг/(кВт*ч) | 3,95 | 2,88 |

## 6. Вывод

```text
H0 увеличивается: 911 -> 1250 кДж/кг
eta_t увеличивается: 32,8 % -> 42,4 %
d0 уменьшается: 3,95 -> 2,88 кг/(кВт*ч)
```

Значит второй цикл выгоднее по КПД и расходу пара.

Но конечная степень сухости у второго цикла меньше:

```text
x2 = 0,794 -> 0,696
```

Это значит, что пар после турбины во втором цикле более влажный.

## 7. Точки для i-S диаграммы

Первый цикл:

```text
I1:  S = 6,408; i = 3042
I2:  S = 6,408; i = 2132
I3:  S = 0,882; i = 268
```

Второй цикл:

```text
II1: S = 6,076; i = 3052
II2: S = 6,076; i = 1802
II3: S = 0,354; i = 101
```

Линия `1-2` вертикальная вниз, потому что:

```text
S2 = S1
```
