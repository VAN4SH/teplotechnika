# Задача 3. Теплопередача через плоскую стальную стенку

Нужно определить:

```text
1) коэффициент теплопередачи от газов к воде;
2) удельный тепловой поток;
3) температуры поверхностей стенки;
4) те же величины при наличии накипи;
5) эпюру изменения температуры.
```

Готовая эпюра:

```text
teplotehnika/zadacha_3_temperature_profile.svg
```

## 1. Исходные данные

Из таблицы 1, вариант 0:

```text
t2 = 40 °C
alpha2 = 90 Вт/(м2*K)
```

Из таблицы 2, вариант 4:

```text
t1 = 450 °C
alpha1 = 5400 Вт/(м2*K)
```

По условию:

```text
lambda_c = 58 Вт/(м*K)        - теплопроводность стали
lambda_н = 3 Вт/(м*K)         - теплопроводность накипи
delta_н = 0,2 мм              - толщина накипи
delta_c = 10 * delta_н        - толщина стальной стенки
```

Переводим толщины в метры:

```text
delta_н = 0,2 мм = 0,0002 м
delta_c = 10 * 0,2 = 2 мм = 0,002 м
```

Разность температур:

```text
t1 - t2 = 450 - 40 = 410 °C
```

## 2. Расчет без накипи

Общее термическое сопротивление:

```text
R = 1/alpha1 + delta_c/lambda_c + 1/alpha2
```

Подставляем:

```text
R = 1/5400 + 0,002/58 + 1/90
R = 0,000185 + 0,0000345 + 0,011111
R = 0,011331 м2*K/Вт
```

Коэффициент теплопередачи:

```text
k = 1/R
k = 1/0,011331
k = 88,3 Вт/(м2*K)
```

Удельный тепловой поток:

```text
q = k * (t1 - t2)
q = 88,3 * 410
q = 36185 Вт/м2
```

Или:

```text
q = 36,2 кВт/м2
```

### Температуры поверхностей стенки

Температура поверхности стали со стороны газов:

```text
tст1 = t1 - q/alpha1
tст1 = 450 - 36185/5400
tст1 = 450 - 6,70
tст1 = 443,3 °C
```

Температура поверхности стали со стороны воды:

```text
tст2 = tст1 - q * delta_c/lambda_c
tст2 = 443,3 - 36185 * 0,002/58
tст2 = 443,3 - 1,25
tст2 = 442,1 °C
```

Проверка через теплоотдачу к воде:

```text
tст2 = t2 + q/alpha2
tст2 = 40 + 36185/90
tст2 = 442,1 °C
```

## 3. Расчет с накипью

Если на стороне газов есть слой накипи, то добавляется сопротивление:

```text
delta_н/lambda_н
```

Общее термическое сопротивление:

```text
R = 1/alpha1 + delta_н/lambda_н + delta_c/lambda_c + 1/alpha2
```

Подставляем:

```text
R = 1/5400 + 0,0002/3 + 0,002/58 + 1/90
R = 0,000185 + 0,0000667 + 0,0000345 + 0,011111
R = 0,011397 м2*K/Вт
```

Коэффициент теплопередачи:

```text
k = 1/R
k = 1/0,011397
k = 87,7 Вт/(м2*K)
```

Удельный тепловой поток:

```text
q = k * (t1 - t2)
q = 87,7 * 410
q = 35973 Вт/м2
```

Или:

```text
q = 36,0 кВт/м2
```

### Температуры поверхностей

Температура наружной поверхности накипи со стороны газов:

```text
tн1 = t1 - q/alpha1
tн1 = 450 - 35973/5400
tн1 = 443,3 °C
```

Температура поверхности стали под накипью:

```text
tст1 = tн1 - q * delta_н/lambda_н
tст1 = 443,3 - 35973 * 0,0002/3
tст1 = 443,3 - 2,40
tст1 = 440,9 °C
```

Температура поверхности стали со стороны воды:

```text
tст2 = tст1 - q * delta_c/lambda_c
tст2 = 440,9 - 35973 * 0,002/58
tст2 = 440,9 - 1,24
tст2 = 439,7 °C
```

Проверка через теплоотдачу к воде:

```text
tст2 = t2 + q/alpha2
tст2 = 40 + 35973/90
tст2 = 439,7 °C
```

## 6. Короткий вариант для переписывания

```text
Дано:
t1 = 450 °C; t2 = 40 °C;
alpha1 = 5400 Вт/(м2*K); alpha2 = 90 Вт/(м2*K);
lambda_c = 58 Вт/(м*K); lambda_н = 3 Вт/(м*K);
delta_н = 0,2 мм = 0,0002 м;
delta_c = 10*delta_н = 2 мм = 0,002 м.

Без накипи:
R = 1/alpha1 + delta_c/lambda_c + 1/alpha2
R = 1/5400 + 0,002/58 + 1/90 = 0,011331 м2*K/Вт.
k = 1/R = 88,3 Вт/(м2*K).
q = k*(t1-t2) = 88,3*(450-40) = 36185 Вт/м2 = 36,2 кВт/м2.
tст1 = t1 - q/alpha1 = 450 - 36185/5400 = 443,3 °C.
tст2 = t2 + q/alpha2 = 40 + 36185/90 = 442,1 °C.

С накипью:
R = 1/alpha1 + delta_н/lambda_н + delta_c/lambda_c + 1/alpha2
R = 1/5400 + 0,0002/3 + 0,002/58 + 1/90 = 0,011397 м2*K/Вт.
k = 1/R = 87,7 Вт/(м2*K).
q = k*(t1-t2) = 87,7*(450-40) = 35973 Вт/м2 = 36,0 кВт/м2.
tн1 = t1 - q/alpha1 = 443,3 °C.
tст1 = tн1 - q*delta_н/lambda_н = 440,9 °C.
tст2 = t2 + q/alpha2 = 439,7 °C.
```
