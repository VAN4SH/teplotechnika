# Решение задачи по теплотехнике: политропное сжатие CO

Это оформление сделано так, чтобы его можно было переписать от руки в тетрадь.
Главное: писать формулы по порядку, затем сразу подставлять числа.

## 1. Исходные данные

По условию и таблицам:

| Величина | Значение |
|---|---:|
| Газ | CO |
| Начальное давление `P1` | `40 бар` |
| Степень повышения давления `N = P2 / P1` | `5` |
| Масса газа `m` | `4 кг` |
| Показатель политропы `n` | `1,2` |
| Начальная температура `t1` | `550 °C` |

Для CO принимаем как для идеального газа:

```text
R = 0,297 кДж/(кг*K)
cv = 0,742 кДж/(кг*K)
cp = 1,039 кДж/(кг*K)
```

Проверка:

```text
cp - cv = 1,039 - 0,742 = 0,297 = R
```

Переводим начальную температуру в Кельвины:

```text
T1 = t1 + 273
T1 = 550 + 273 = 823 K
```

Переводим давление:

```text
P1 = 40 бар = 4000 кПа
```

Так удобно, потому что:

```text
1 кПа * м3 = 1 кДж
```

## 2. Конечное давление

По условию:

```text
N = P2 / P1
```

Отсюда:

```text
P2 = N * P1
P2 = 5 * 40 = 200 бар
```

В кПа:

```text
P2 = 200 бар = 20000 кПа
```

## 3. Конечная температура

Для политропного процесса идеального газа:

```text
T2 / T1 = (P2 / P1)^((n - 1) / n)
```

Так как `P2 / P1 = N`, можно писать:

```text
T2 = T1 * N^((n - 1) / n)
```

Подставляем:

```text
T2 = 823 * 5^((1,2 - 1) / 1,2)
T2 = 823 * 5^(0,2 / 1,2)
T2 = 823 * 5^0,1667
T2 = 823 * 1,307
T2 = 1076 K
```

В градусах Цельсия:

```text
t2 = T2 - 273
t2 = 1076 - 273 = 803 °C
```

## 4. Удельные объемы газа

Используем уравнение состояния идеального газа:

```text
P * v = R * T
```

Отсюда:

```text
v = R * T / P
```

Начальный удельный объем:

```text
v1 = R * T1 / P1
v1 = 0,297 * 823 / 4000
v1 = 0,0611 м3/кг
```

Конечный удельный объем:

```text
v2 = R * T2 / P2
v2 = 0,297 * 1076 / 20000
v2 = 0,0160 м3/кг
```

Проверка по смыслу: при сжатии давление увеличилось, а объем уменьшился.

## 5. Изменение внутренней энергии

Внутренняя энергия идеального газа зависит только от температуры:

```text
Delta U = m * cv * (T2 - T1)
```

Находим разность температур:

```text
T2 - T1 = 1076 - 823 = 253 K
```

Подставляем:

```text
Delta U = 4 * 0,742 * 253
Delta U = 751 кДж
```

Ответ:

```text
Delta U = +751 кДж
```

Знак плюс означает, что внутренняя энергия газа увеличилась.

## 6. Работа политропного сжатия

Работа газа в политропном процессе:

```text
Lгаз = m * R * (T2 - T1) / (1 - n)
```

Так как `n = 1,2`, знаменатель `1 - n` отрицательный. Поэтому работа газа при сжатии получается отрицательной.

```text
Lгаз = 4 * 0,297 * 253 / (1 - 1,2)
Lгаз = 300,6 / (-0,2)
Lгаз = -1503 кДж
```

Если в ответе нужна именно работа сжатия, то берут модуль:

```text
Lсж = 1503 кДж
```

То есть внешняя сила совершила над газом работу примерно `1503 кДж`.

## 7. Количество отведенного тепла

Первый закон термодинамики:

```text
Q = Delta U + Lгаз
```

Подставляем работу газа со знаком минус:

```text
Q = 751 + (-1503)
Q = -752 кДж
```

Знак минус означает, что теплота от газа отводится.

Количество отведенного тепла по модулю:

```text
Qотв = 752 кДж
```

## 8. Итоговые результаты

```text
P2 = 200 бар
T2 = 1076 K
t2 = 803 °C
v1 = 0,0611 м3/кг
v2 = 0,0160 м3/кг
Delta U = +751 кДж
Lгаз = -1503 кДж
Lсж = 1503 кДж
Q = -752 кДж
Qотв = 752 кДж
```

## 9. Как построить график в координатах P-v

Ось `v` горизонтальная, ось `P` вертикальная.

Масштаб можно взять такой:

```text
по оси v: от 0,015 до 0,065 м3/кг
по оси P: от 40 до 200 бар
```

Уравнение политропы:

```text
P * v^n = const
```

Для построения удобно считать точки по формуле:

```text
v = v1 * (P1 / P)^(1 / n)
```

Таблица точек:

| P, бар | v, м3/кг |
|---:|---:|
| 40 | 0,0611 |
| 60 | 0,0436 |
| 80 | 0,0343 |
| 100 | 0,0285 |
| 120 | 0,0245 |
| 160 | 0,0193 |
| 200 | 0,0160 |

Как выглядит график:

```text
1-я точка: справа внизу, P1 = 40 бар, v1 = 0,0611 м3/кг.
2-я точка: слева вверху, P2 = 200 бар, v2 = 0,0160 м3/кг.
Процесс идет от точки 1 к точке 2.
Стрелка направлена вверх и влево.
Кривая похожа на гиперболу: при уменьшении объема давление растет.
```

## 10. Как построить график в координатах T-s

Ось `s - s1` горизонтальная, ось `T` вертикальная.

Для графика можно принять:

```text
s1 = 0
```

Тогда считаем изменение энтропии от начального состояния:

```text
Delta s = cp * ln(T / T1) - R * ln(P / P1)
```

Здесь `ln` - натуральный логарифм.

Для конечной точки:

```text
Delta s2 = cp * ln(T2 / T1) - R * ln(P2 / P1)
```

Подставляем:

```text
Delta s2 = 1,039 * ln(1076 / 823) - 0,297 * ln(200 / 40)
Delta s2 = 1,039 * ln(1,307) - 0,297 * ln(5)
Delta s2 = 1,039 * 0,2677 - 0,297 * 1,609
Delta s2 = 0,278 - 0,478
Delta s2 = -0,200 кДж/(кг*K)
```

Таблица точек:

| P/P1 | T, K | s - s1, кДж/(кг*K) |
|---:|---:|---:|
| 1,0 | 823 | 0,000 |
| 1,5 | 881 | -0,050 |
| 2,0 | 924 | -0,086 |
| 2,5 | 959 | -0,114 |
| 3,0 | 989 | -0,137 |
| 4,0 | 1037 | -0,172 |
| 5,0 | 1076 | -0,200 |

Как выглядит график:

```text
1-я точка: справа внизу, T1 = 823 K, s - s1 = 0.
2-я точка: слева вверху, T2 = 1076 K, s - s1 = -0,200.
Процесс идет от точки 1 к точке 2.
Стрелка направлена вверх и влево.
Температура растет, а энтропия уменьшается, потому что при политропном сжатии тепло отводится.
```

Готовый график смотри в файле:

```text

```

## 11. Короткий вариант для переписывания в тетрадь

Если нужно записать компактно, порядок такой:

```text
Дано:
CO; P1 = 40 бар; N = P2/P1 = 5; m = 4 кг; n = 1,2; t1 = 550 °C.
R = 0,297 кДж/(кг*K); cv = 0,742 кДж/(кг*K); cp = 1,039 кДж/(кг*K).

T1 = t1 + 273 = 550 + 273 = 823 K.
P2 = N * P1 = 5 * 40 = 200 бар.

T2 = T1 * (P2/P1)^((n-1)/n)
T2 = 823 * 5^((1,2-1)/1,2) = 1076 K.
t2 = 1076 - 273 = 803 °C.

v1 = R*T1/P1 = 0,297*823/4000 = 0,0611 м3/кг.
v2 = R*T2/P2 = 0,297*1076/20000 = 0,0160 м3/кг.

Delta U = m*cv*(T2-T1)
Delta U = 4*0,742*(1076-823) = 751 кДж.

Lгаз = m*R*(T2-T1)/(1-n)
Lгаз = 4*0,297*(1076-823)/(1-1,2) = -1503 кДж.
Lсж = 1503 кДж.

Q = Delta U + Lгаз
Q = 751 - 1503 = -752 кДж.
Qотв = 752 кДж.
```
